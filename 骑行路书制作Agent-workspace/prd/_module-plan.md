# 骑行路书制作 Agent · MVP PRD 模块计划

- 计划日期 2026-11-22
- 模块计划已确认。各模块按顺序追加到 `prd/PRD.md`。

## 已确认输入

首版面向全国骑友，服务个人路书制作。产品为延续 AI Cycler 视觉风格的独立 Web 工具。手动与 Agent 使用同一份路线草稿。Agent 获取地图信息，支持里程、累计爬升、环线、必经点和补给。导入验收覆盖顽鹿运动、行者和 iGPSPORT。GPX 1.1 是拟采用的文件格式。

来源见[定型摘要](../shaping/06-shaped-brief.md)、[产品定型](../shaping/01-product-shaping.md)、[MVP 范围](../shaping/03-scope.md)、[页面与流程](../shaping/04-pages-and-flows.md)及[技术验证事项](../shaping/05-open-questions.md)。

## 拟编写模块

1. **产品目标、范围与主流程**

   写明文档版本、目标用户、个人出发前规划场景、首版范围和成功指标定义。用流程图说明地图选点与对话两条入口如何汇合到路线草稿、编辑与导出。明确地图、路线卡片和对话入口的职责。指标阈值待验证。

2. **地图手动创建与编辑**

   写明地图选点和地点搜索、点到点和环线、添加和移动途经点、删除和重排、局部重算、距离和爬升更新等交互。覆盖同名地点、无路线、断段、超时和快速连续修改。验收检查界面状态、受影响路段、旧结果处理及完整版本的导出条件。

3. **Agent 规划与对话改线**

   写明解析条件、地点澄清、搜索必经点与补给、候选生成、骑行算路、高程查询与累计爬升估算、约束校验和用户应用。区分「50 公里左右」与「最多 50 公里」、「尽量少爬升」与「累计爬升不超过 400 米」。说明候选结果的里程和爬升偏差、补给绕行、环线闭合、无解和数据缺失时的表现，以及改线如何应用到当前草稿。验收包含数值边界、硬条件冲突和高程无法核实。

4. **GPX 导出与三端导入验收**

   写明从用户选定的完整版本生成文件的条件、GPX 1.1 坐标与轨迹检查、下载失败重试，以及用户在三款 App 中手动导入的验证路径。用同一份生成文件分别在顽鹿运动、行者及 iGPSPORT 验证可以导入为路书、中文名称可识别、起终点与道路位置对齐、轨迹连续和环线闭合。每款 App 独立记录通过、失败或待验证，记录系统、App 版本和代表码表型号。设备复验和长路线等边界纳入用例，实际阈值以验证结果为准。

5. **数据、异常与发布前待决事项**

   汇总路线版本、轨迹与高程的来源及坐标、草稿权限与保存方式，以及计量和覆盖验证。列出高德轨迹导出授权、坐标对齐、高程误差、全国算路覆盖和三端实测的验收证据。文末附自检与待完善清单。
