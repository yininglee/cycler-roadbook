# 输入材料

- 产品名：骑行路书制作 Agent
- 工作区创建日期：2026-11-21
- 阶段：首版产品范围已确认，技术方案待验证

## 用户提出的需求

- 用户可以在地图上创建、编辑和导出骑行路线。
- Agent 能理解用户需求、调用地图信息并生成符合需求的骑行路书。
- 评估是否需要接入高德地图。
- 界面风格暂时沿用 AI Cycler。

## 界面参考

- 用户提供的附件是 AI Cycler 既有应用的 `app/` 源码。视觉参考来自 `globals.css`、`components/chat-home.tsx` 和 `components/bottom-nav.tsx`。
- 附件中的训练、骑行记录、账号及对话能力属于原应用。第一版功能范围以用户在本次对话提出的需求为准。

## 2026-11-22 用户确认

- 面向全国骑友，用于个人规划和使用路线。
- 首版 Agent 要能获取地图信息，并理解里程、爬升、环线、必经点和补给。
- 产品为延续 AI Cycler 视觉风格的独立 Web 工具。
- 首批导入目标为顽鹿运动、行者和 iGPSPORT。
